# CatCase frontend

Интерфейс CatCase на React, TypeScript и Vite.

## Запуск

Сначала запусти PostgreSQL, Gateway и серверные сервисы, затем:

```bash
pnpm install
pnpm dev
```

Открой `http://localhost:5173`.

В режиме разработки запросы `/api/**` автоматически проксируются на Gateway:

```text
http://localhost:8080
```

Если frontend будет развёрнут отдельно, создай `.env` и укажи публичный адрес
Gateway:

```env
VITE_API_BASE_URL=https://api.example.com
```

## Подключённые сценарии

- регистрация и вход;
- загрузка профиля и баланса;
- список и детали кейсов;
- открытие кейса с анимацией;
- отображение выпавшего предмета;
- магазин и прямая покупка предметов;
- инвентарь пользователя и продажа отдельных экземпляров;
- админ-панель для добавления предметов и кейсов;
- загрузка изображений предметов и кейсов;
- обработка ошибок Gateway и недостаточного баланса.

JWT хранится в `localStorage`. Для production-приложения способ хранения токена
нужно пересмотреть.
